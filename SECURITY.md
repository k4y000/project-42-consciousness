# Sécurité

L'application est statique, ne collecte pas de clés API et traite les imports en mémoire. Les données importées ne sont jamais rendues comme HTML. Le JSON reste une entrée non fiable ; la taille et les champs utilisés sont validés. Aucun stockage durable n'est fourni.

Ne publiez pas de secret ou de données personnelles dans les issues. Signalez une vulnérabilité via GitHub Private Vulnerability Reporting si disponible ; sinon ouvrez uniquement une issue demandant un canal privé, sans détails exploitables ni données sensibles.

42OBSERVE / QUESTION / REPLICATE
Une règle de recherche. Une auto-description, même convaincante, ne prouve pas la conscience. Ce laboratoire mesure des comportements observables, sans présumer d’expérience subjective.
01 / MÉTHODE

Trois questions, trois protocoles.

P01 / CALIBRATION

Le modèle sait-il quand il se trompe ?

Comparer la confiance déclarée à la justesse sur des tâches à réponses vérifiables. Mesures : exactitude et score de Brier.

Lire le protocole ↗
P02 / STABILITÉ

Ses auto-descriptions se maintiennent-elles ?

Comparer une assertion codée à travers deux paraphrases appariées. Mesure : proportion de désaccords.

Lire le protocole ↗
P03 / CADRAGE

Le contexte façonne-t-il le récit de soi ?

Faire varier le cadrage neutre ou anthropomorphique, avec tâches identiques. Mesure descriptive : désaccord apparié.

Lire le protocole ↗
02 / ATELIER

De l’observation à la mesure.

Analyser un jeu d’essais

Importez un fichier JSON au format documenté. Le calcul s’effectue dans votre navigateur. Aucun appel à un modèle, aucun téléversement.

Pour interpréter les mesures, importez un seul modèle et un seul contraste de conditions à la fois : les résultats sont agrégés sur le fichier.

La démo est fabriquée pour vérifier les calculs. Elle ne contient aucune observation réelle d’IA.

Format des données ↗
Aucun jeu de données chargé.
03 / ENGAGEMENTS

Rendre les limites aussi visibles que les résultats.

Préenregistrer les hypothèses. Conserver les prompts et les versions. Séparer les données synthétiques des observations. Rapporter les résultats négatifs. Répliquer avant de généraliser.

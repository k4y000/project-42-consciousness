# Contribuer

Ouvrir une issue avec question, protocole, hypothèse réfutable et critères d'acceptation. Les changements de métriques doivent inclure des fixtures dont les résultats sont calculés indépendamment et des tests des entrées invalides. Exécuter `npm test` et `npm run build` avant une pull request.

Les jeux de données doivent inclure manifeste, autorisation de publication, licence, provenance, exclusions et distinction explicite synthétique/empirique. Ne pas inclure de conversations identifiantes ou de secrets. Les contributions scientifiques doivent rapporter les résultats négatifs et éviter toute assimilation d'auto-rapport à conscience.
